Problēma:
Daudzi cilvēki aizmirst regulāri laistīt savus augus. Tā rezultātā augi izkalst vai tiek kopti nepareizi. Īpaši aktuāli tas ir skolēniem, studentiem un cilvēkiem ar aizņemtu ikdienu.
Tāpēc tiek izstrādāta tīmekļa lietotne “PlantCare Tracker”, kas ļauj: pievienot augus; saglabāt informāciju par laistīšanas datumiem; atzīmēt pēdējo laistīšanas reizi;
ērti pārskatīt visu augu sarakstu. Programma palīdz lietotājiem neaizmirst par augu kopšanu un organizēt ikdienas paradumus.



Aptaujas rezultāti
Tika veikta neliela aptauja draugu vidū.

Jautājumi:
Vai jums mājās ir augi?
Vai jūs mēdzat aizmirst tos aplaistīt?
Vai izmantotu vienkāršu lietotni augu kopšanai?
Rezultāti:
80% cilvēkiem ir mājas augi;
65% atzina, ka reizēm aizmirst tos aplaistīt;
75% izmantotu vienkāršu ieradumu sekotāju.



Es izvēlējas Agile pieeja. Jo tas ļauj pakāpeniski uzlabot projektu; ātri testēt funkcionalitāti; viegli labot kļūdas; sadalīt darbu vairākos posmos. Arī es izmantoju HTML, CSS un JavaScript 



Kā izmantot programmu?

Ierakstiet auga nosaukumu.
Nospiediet pogu “Pievienot”.
Kad augs ir aplaistīts, nospiediet “Aplaistīts”.
Programma saglabās datumu automātiski.
Ja nepieciešams, augu var dzēst.
